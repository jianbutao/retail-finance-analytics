# 客户流失预测与精准召回（机器学习）

基于真实在线零售交易数据，用机器学习预测客户未来 3 个月是否流失，并输出可落地的精准召回名单。

## 1. 数据与窗口
- 数据：UCI Online Retail II（在线零售交易），时间跨度 2009-12 至 2011-12；
- 建模样本：2722 名客户（观察窗口内有购买）；
- 双窗口设计（防止时间泄漏）：
  - 观察窗口 2011-01 ~ 2011-06：计算特征；
  - 预测窗口 2011-07 ~ 2011-09：生成标签；
- 标签：预测窗口内无任何购买 = 流失（churn=1），流失率 47%。

## 2. 特征（6 个）
- recency_days：最近一次购买距观察期末天数；
- frequency：订单数；
- monetary：总消费金额；
- n_products：购买的不同商品数；
- avg_order_value：平均每笔金额；
- active_days：有购买的不同天数。

## 3. 模型与评估
对比逻辑回归（LR）、随机森林（RF）、梯度提升（GB），通过 5 折交叉验证选型：

| 模型 | 5折 CV AUC |
|---|---|
| LR（最终选定） | 0.755 |
| GB | 0.747 |
| RF | 0.716 |

最终模型（LR）测试集指标：
- AUC 0.752、PR-AUC 0.697、KS 0.429；
- Recall@20% 0.301、Lift@20% 1.50。

## 4. 业务落地
- 按"风险 × 价值"分四象限：高风险 492 人（18.1%）、中风险 1425 人、低风险 805 人；
- 其中 57 名"高风险 + 高价值"客户为重点挽留对象（涉及金额约 16 万）；
- 输出名单：全量风险表、TOP200 名单、重点挽留名单；
- 策略：高价值客户人工+大额券，低价值客户低成本自动触达，避免预算浪费。

## 5. 目录结构
- src/：00 连接验证 → 01 数据集 → 02 LR基线 → 03 树模型 → 04 评估 → 05 落地；
- reports/：数据集、ROC/PR 图、各类名单。

## 6. 已知局限与改进
- 特征仅 6 个，可补充购买间隔、退货率、消费趋势等；
- 单次时间切分、样本有限，可改为滚动时间窗交叉验证；
- 概率未做校准，召回策略上线后需 A/B 实验验证真实效果。
