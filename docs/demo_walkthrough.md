# 面试演示路线

项目：零售交易数据驱动的经营分析与风险信号识别

定位：基于单个零售商历史交易数据的分析演示，
不是实时财务系统，也不是经验证的企业风险评级模型。

## 1. 数据与经营概况

展示交易规模、月度趋势与边界截断提示。
说明清洗如何处理跨表重叠、缺失客户编号及取消记录。
交易金额不等于会计确认收入、利润或到账现金流。

## 2. 商品与客户结构

展示商品交易净额排名、客户金额集中情况和RFM分群。
强调客户结构受编号识别覆盖率影响，
不同模块的观察窗口需要分别说明。

## 3. 预测实验

说明按时间划分训练、验证与测试集。
四周移动平均由验证集比较选定。
测试MAE为50,992.56 GBP，WAPE为18.42%。
这是逐周更新的一步预测，不能保证未来效果，
也不能把100%-WAPE称为准确率。

## 4. 经营信号

展示月度信号的基准、阈值和适用限制。
以客户12346的大额冲销展示敏感性分析：
同时排除成对记录后取消占比下降，交易净额不变。
正式数据不删除，触发信号不等于查明经营原因。

## 5. AI辅助分析

展示已归档摘要、证据编号与生成记录。
采用人工对话生成方式，未接入在线生成API。
哈希用于检查文件是否变化，不验证语义正确性。
摘要需要人工核查，不引入证据之外的结论。

## 项目价值

将清洗、指标定义、数据库对账、客户分析、预测评估、
规则观察和证据约束的AI摘要整合为可展示的分析流程。
