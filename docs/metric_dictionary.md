# 指标字典 v1

所有金额单位 GBP。保留真实三位小数单价；汇总后展示两位小数。对账使用整数千分之一英镑，不逐行先舍入为便士。

| 指标 | 定义 | 限制 |
|---|---|---|
| 商品正向交易金额 | 商品候选且正向交易的数量×单价之和 | 不是会计收入、利润或到账现金 |
| 商品取消／冲销金额 | 商品候选且取消或冲销记录的带符号金额之和取负 | 未逐笔匹配原订单，不证明实际退款 |
| 商品交易净额 | 正向金额减取消金额 | 可能包含跨期取消，不是利润 |
| 取消金额占比 | 取消金额÷同观察期正向金额×100 | 不是订单退款率；分母为零时缺失 |
| 正向订单数 | 含商品正向明细的不同 invoice_no 数 | 同一订单多行只计一次 |
| 已识别购买客户数 | 商品正向明细中非空 customer_id 去重 | 不包含未识别客户 |
| 客户金额覆盖率 | 已识别客户正向金额÷全部商品正向金额 | 不是客户人数覆盖率 |
| 客户集中度 | 指定前N客户金额占已识别或全部正向金额 | 必须标明分母；正向排名会受冲销影响 |
| 有销售记录天数 | 至少一条商品正向记录的日历日期数 | 不是已确认营业天数 |
| R | 截止日期减最近正向交易的日历日期 | 不逐笔扣除后来取消的订单 |
| F | RFM窗口内正向订单去重数 | 同上 |
| M | RFM窗口内商品交易净额 | 仅净额为正的客户获得M分数 |
| MAE | 平均绝对预测误差 | GBP，越低越好 |
| WAPE | 绝对误差合计÷实际金额绝对值合计×100 | 不能用100%-WAPE称为准确率 |
| 平均偏差 | 平均(预测-实际) | 正为高估，负为低估；误差可抵消 |

## 固定时间口径

- 全期经营与商品分析：清洗数据全部期间，2009-12-01至2011-12-09；最后一个月边界截断。
- RFM：2010-12-01（含）至2011-12-01（不含）。4293名正向购买客户；取消记录单独汇总。
- 预测：截止2011-12-01（不含），周一至周日。103个完整日历周，按79/12/12划分。
- 无记录周保留NaN和日历位置；缺失记录不证明零营业额。未被边界截断也不证明每日完整。
- 预测是每周更新历史后的下一周预测，不是一次预测12周。测试集已经查看，不能再用于调参。
- 不同窗口不能直接合并为一个统一时点的实时风险判断；未来看板必须标注各自期间。

## 数据处理

跨表重叠仅在业务字段完全相同且两表出现次数相同时移除第二表副本；保留表内重复并提供敏感性分析。特殊编码与商品白名单使用固定清洗批次metadata.json中的v1规则，不能根据预测结果改变规则。
